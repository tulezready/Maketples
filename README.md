# MaketPles ENB

Official online marketplace for small and medium enterprises in East New Britain Province, Papua New Guinea.

Built for the **Division of Commerce & Industry**, East New Britain Provincial Administration.

> **Status: design preview.** Every page here runs on sample data held in the browser. No database is connected, no accounts are real, and no payments are processed. See [What's next](#whats-next).

---

## What's in here

| File | What it is | Who uses it |
|---|---|---|
| `index.html` | The public marketplace | Buyers |
| `register.html` | Application form to join the platform | Businesses applying |
| `seller.html` | Seller portal — listings, orders, payouts | Approved SMEs |

| `data.json` | Marketplace content | Generated by the intake tool |
| `logo.svg` | The ENBPA Division mark, used on every page | — |
| `photos/` | Product and business photographs | Filenames referenced from `data.json` |
| `docs/` | Scope of work, build plan, launch checklist | Project record |

## How the pieces fit together

```
                        ┌──────────────────────┐
   Business applies ──▶ │   register.html      │
   on the web           └──────────┬───────────┘
                                   │
   Officer registers    ┌──────────▼───────────┐
   at conference    ──▶ │  tools/intake.html   │  (works offline)
   or in the field      └──────────┬───────────┘
                                   │
                        ┌──────────▼───────────┐
                        │     admin.html       │  Division approves
                        │  approvals + review  │  businesses and listings
                        └──────────┬───────────┘
                                   │
                   ┌───────────────┴───────────────┐
                   ▼                               ▼
          ┌─────────────────┐            ┌──────────────────┐
          │  seller.html    │            │   index.html     │
          │  SME manages    │───────────▶│  buyers browse   │
          │  own listings   │  approved  │  and order       │
          └─────────────────┘  listings  └──────────────────┘
```

**Two doors in, one queue.** A business can apply for itself on the web, or be registered by an officer using the intake tool. Both land in the same review queue in the Division panel. Nothing reaches buyers until the Division approves it.

## Running it locally

Everything is plain HTML, CSS and JavaScript. No build step, no dependencies.

```bash
# from the repo root
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

A local server is needed rather than opening the files directly, because `index.html` fetches `data.json`.

## Publishing to GitHub Pages

1. Push this repository to GitHub.
2. **Settings → Pages → Source: Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The site appears at `https://<user>.github.io/<repo>/`.

Once the `.com.pg` domain is approved, add a `CNAME` file containing the domain and point the DNS at GitHub Pages.

## Updating the marketplace content

No code editing required.

1. Open `tools/intake.html` and enter businesses and products.
2. Go to **Export & backup → Download data.json**.
3. Replace `data.json` in this repository.
4. Put the photographs in `photos/`, using the exact filenames recorded during collection.
5. Commit and push. GitHub Pages redeploys automatically.

The homepage slideshow is built from any business ticked as **Featured** in the intake tool. Six to twelve works well.

### Photograph naming

Use `DISTRICT_Business_subject_01.jpg`, for example:

```
photos/KOKOPO_Vunamami_hero.jpg
photos/KOKOPO_Vunamami_cocoa_01.jpg
photos/GAZELLE_Toma_blouse_01.jpg
```

Landscape, at least 1800px wide for slideshow images, taken in daylight. Leave clear space on the left third of slideshow photographs — the headline sits there.

## The database

`db/schema.sql` is complete and has been tested against PostgreSQL 16. Run it once, top to bottom, in the Supabase SQL editor on a **new** project. It is safe to re-run.

It creates ten tables plus supporting views, and enforces these rules in the database itself rather than in the interface:

- Only businesses approved by the Division are visible to the public.
- Only listings set to `live` by the Division appear on the site. **A seller cannot publish their own listing.**
- **A seller cannot mark their own order as paid.** Payment status is set only after the payment gateway confirms it.
- A seller cannot see or edit another business's listings, orders or payouts.
- A seller cannot alter their own payout figures.
- Every price change is logged with a timestamp, giving the Division genuine provincial price data.
- Order lines store the price at the moment of sale, so later price changes never alter a completed order.

After running it:

1. Create a public storage bucket named `product-photos`.
2. Promote your own account:
   ```sql
   update profiles set role = 'division_admin' where id = '<your auth user id>';
   ```
3. Import collected data using the SQL export from the intake tool.

## What's next

Current state is a working catalogue plus a data-collection system. To become a live marketplace it needs:

- [ ] Supabase project on the Pro tier, schema applied
- [ ] All four apps connected to the database instead of sample data
- [ ] Real authentication for sellers and Division staff
- [ ] Payment gateway integration (BSP IPG or Cloudcode) — pending merchant approval
- [ ] SMS notifications for orders and "send home" recipients
- [ ] `.com.pg` domain, registered through PNG University of Technology

**Fallback:** if the payment gateway is not approved in time, the platform launches as a live catalogue with agent and offline settlement, and card payment is switched on later. This protects the launch date.

See `docs/build-plan.md` for the full outstanding list and the data still to be collected.

## Conventions worth keeping

- **Seven industries**, fixed: retail, wholesale, tailoring, arts & crafts, small scale downstream processing, fresh produce, food crops (rice & spices). These come from the Division's own SME listing — do not invent new ones.
- **Four districts**, fixed: Gazelle, Kokopo, Rabaul, Pomio.
- **Colours** are taken from the East New Britain provincial flag: red `#7E0F12`, green `#00702F`, black, on bone white.
- The **ENBPA logo** (`logo.svg`) is the Administration's own mark and is kept in this repository, so the site has no dependency on any other project. If the Administration supplies an updated official file, replace `logo.svg` and every page picks it up.
